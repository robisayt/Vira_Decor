Фото категорії «wardrobes».

Покладіть сюди знімки і додайте їхні шляхи у content/furniture.ts:

  { src: "/furniture/wardrobes/nazva-fajlu.jpg", ratio: "tall" }

ratio: "wide"   — горизонтальний кадр (займає дві колонки на ПК)
       "tall"   — вертикальний
       "square" — квадратний

Порядок у масиві = порядок показу на сторінці.
Якість: проганяйте фото через npm run photos, не зменшуйте заздалегідь.
